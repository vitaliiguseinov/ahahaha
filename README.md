# Сканер E327 v1.3
Android-приложение для Renault Duster через обычный (Classic) Bluetooth ELM327.

Что нового в 1.3:
- исправлен разбор кодов Mode 03 для CAN (лишний байт «количество кодов»);
- исправлено чтение параметров (раньше PID 0C/05/0B/0D всегда давали «нет ответа»);
- подключение к дешёвым клонам ELM327 (запасной способ через RFCOMM-канал 1);
- ожидание автоопределения протокола, подтверждение перед очисткой ошибок;
- сборка APK в облаке через GitHub Actions (файл .github/workflows/build.yml).

## Как получить APK без Android Studio
1. Создай аккаунт и новый репозиторий на github.com.
2. Загрузи в него всё содержимое этой папки (включая скрытую папку .github).
3. Вкладка Actions → Build APK → Run workflow (или просто дождись запуска после загрузки).
4. Через 3–5 минут открой завершённый запуск → внизу Artifacts → ScannerE327-apk → скачай, распакуй.
5. Установи app-debug.apk на телефон (разреши установку из неизвестных источников).
6. Сопряги ELM327 в настройках Bluetooth телефона, включи зажигание, открой приложение.
